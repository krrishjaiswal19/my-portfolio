# 🚀 Animated Personal Portfolio

This is my personal developer portfolio built using **React.js** and **Tailwind CSS**.
It showcases my skills, projects, and learning journey as I grow in the field of web development.

🌐 **Live Demo: (https://krrish-jaiswal.vercel.app/)

---

## 📌 About the Project

This portfolio is not just a static website — it's a continuously evolving project where I:

* Showcase my latest work
* Share what I am currently learning
* Improve UI/UX and performance over time

I believe in **learning by building**, and this project reflects my journey.
